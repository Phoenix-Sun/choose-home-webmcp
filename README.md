# 選好宅／找房比較助手

以公開待售物件為資料來源的自然語言找房比較工具。Node 伺服器會即時查詢原始物件網站的公開搜尋資料，前端與 ChatGPT WebMCP 工具共用同一份條件、候選、比較及保留狀態。

## 投稿與來源聲明

本專案為參賽者以個人身分製作的開源實驗作品，並非原始資料網站的官方服務或受託專案，也不代表資料提供者立場。本專案僅整理無需登入即可公開瀏覽的資訊，並提供原始物件頁連結供核對。

## 本機執行

需求：Node.js 20 以上。

```bash
npm install
npm run dev
```

預設網址為 `http://127.0.0.1:5173`。若該埠已使用，可指定 `PORT=5174 npm run dev`。

正式模式：

```bash
npm run build
npm start
```

## 已接通功能

- 自然語言解析：縣市、行政區、總價、房數、坪數、屋齡、捷運距離與比較偏好。
- 即時公開物件：伺服器端連接原始物件網站的公開買屋搜尋，分頁載入全部符合候選，前 10 名僅是目前排序建議。
- 公開證據補充：查詢物件公開詳情及公開介面提供的內政部實價登錄同區相近條件成交；目前不宣稱為物件半徑內成交。
- 可驗證交通資訊：只呈現公開物件頁提供的最近捷運站與距離，不自行推算通勤分鐘。
- 失敗邊界：即時來源失敗時直接明示資料無法取得，不以過期或模擬物件代替，也不自行估值。
- 協作狀態：Agent 重查時保留使用者釘選物件；地圖、候選表、洞察及決策卡同步更新。
- WebMCP：AI 模式提供 18 項工具，包含搜尋、進度、分頁、條件預演與確認、收藏、比較、證據更新與資料缺口。一般手動模式不註冊 Agent 工具，避免隱形狀態變更。

## 資料邊界

只處理網站無需登入即可取得的公開欄位。不使用會員、業務、加盟店、登入後資料、內部 API、帳號或金鑰，也不包含預約、聯絡及交易送出流程。公開介面若變更，系統會明確顯示來源錯誤，不會用過期或模擬物件代替。

公開可瀏覽不等於取得再利用授權。依 WebMCP Challenge 官方規則，投稿者仍須在投稿前確認第三方 API、資料、名稱與商標的使用授權；本專案的免責聲明不取代該授權。

## 驗證

```bash
npm test
npm run build
```

瀏覽器驗收應確認：即時來源狀態、自然語言重查、載入更多後的同範圍條件預演、釘選後重查保留、實價證據補充、AI 模式 18 個 WebMCP 工具可發現、手動模式不註冊工具，以及 390px 手機寬度沒有水平溢位。

## Vercel 部署

本專案可使用 Vercel Hobby 發布。Vercel 會以 Vite 建置前端，並將 `api/` 內的四個端點部署為 Node.js Functions；正式 API 與本機伺服器共用 `server.mjs` 的查詢與驗證邏輯。

```bash
npm run build
vercel
```

部署後先確認 `/api/health`，再執行即時搜尋、資料補充、WebMCP 工具發現及手機版驗收。Vercel 設定將 Function 固定在新加坡區域，降低台灣使用者與公開資料來源之間的網路距離。
